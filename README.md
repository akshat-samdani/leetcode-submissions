# LeetCode Submissions

Accepted submissions from LeetCode.com are synced here automatically by a scheduled GitHub Actions workflow.

- Source account: `Akshat202002`
- Sync cadence: hourly
- Only accepted submissions are exported
- The LeetCode session is stored only as the encrypted `LEETCODE_SESSION` repository secret

If LeetCode invalidates the session, update that secret and re-run the workflow from the Actions tab.
